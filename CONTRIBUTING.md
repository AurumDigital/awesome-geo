# Contributing

Thanks for helping improve this list.

- Add resources that are genuinely useful for understanding or practising GEO: official documentation, research, well-documented tools and in-depth guides.
- Prefer primary sources (search engines, AI companies, researchers) over summaries.
- One resource per pull request, in the right section, formatted as `- [Name](link) - Short description ending with a period.`
- No affiliate links, paid placements or thin promotional pages.
